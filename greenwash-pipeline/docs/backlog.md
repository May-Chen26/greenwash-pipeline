## 合并规则

每个 Issue 一人负责，一个短期分支，一个小 PR。更改接口前在 Issue 中明确旧/新字段与下游影响。PR 写清问题、改动、验证和限制；另一成员审核。每天集成一个可运行版本，避免比赛结束前才集中合并。
